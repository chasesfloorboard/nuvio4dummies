Welcome

First, let's see what you have.

This guide adapts to what you've already completed. You can skip anything you don't need.

You will never need to give this website your Real-Debrid password or API key.
Step 1

Get Nuvio

Nuvio is the application you'll use to browse your media library.

Visit Nuvio's official website ↗
Download the version intended for your device. Install it, open it, and create or sign into your account.

When you're ready, return here and continue.

Step 2

Set up Real-Debrid

Real-Debrid is a separate paid service. It provides access to supported cached content.

Visit Real-Debrid ↗
Create an account and choose a subscription if you want to use its premium features.

Already have an account? You can move on.

Step 3

Configure Comet

Comet is an addon that searches for compatible content sources.

Open Comet configuration ↗
Configure Real-Debrid directly on the official Comet configuration page. Treat your personalized manifest URL as a private credential.

Choose your preferences, configure the service, and copy your generated addon manifest URL.

Step 4

Install Comet in Nuvio

Return to Nuvio and open its addon management area.

  1. Open Nuvio settings.
  2. Find Addons or Add Addon.
  3. Choose the option to add an addon by URL.
  4. Paste your Comet manifest URL.
  5. Follow Nuvio's installation prompts.
Menu names may vary by Nuvio version and device. Never share your personalized addon URL publicly.
Final step

Check your setup

Use this checklist to make sure you've completed each stage.

If something isn't working, revisit the relevant step and double-check your configuration.

You're ready to go!

Option 1 · Quick

Netflix, Disney+, Hulu and more, right on your homepage.

This adds a Streaming Services collection to Nuvio with a folder for each service. Every folder has Popular Movies, Popular Series, Latest Movies and Latest Series rows.

NetflixPrime VideoDisney+HBO MaxApple TV+Paramount+HuluPeacockCrunchyroll
No extra addon, API key or account needed. The rows use TMDB, which is built into Nuvio. This only organizes what you browse. It doesn't give access to any service's subscription.
Importing replaces all collections on this account. Have some you want to keep? Tap the two-squares icon first to copy a backup, or import on a TV instead, which adds without replacing.
  1. Tap Copy collection below.
  2. Open the Nuvio app and go to Settings → Layout → Collections.
  3. Tap the clipboard icon at the top-right (not the two-squares icon next to it).
  4. Paste into the box, then tap Import.
Download file
  1. In the Nuvio TV app, open Settings and find Collections.
  2. Choose Import, then pick the URL option.

/collections/streaming-services.json

Import in the installed Nuvio app; the website version (nuvioweb.space) can't import. Once imported, it syncs to your other devices. Rows use US streaming availability. Don't see Collections? Update Nuvio.

Option 2 · Full setup with MDBList

Get the complete homepage: services, genres and more.

You'll make two free accounts, connect them to AIOMetadata, and get your own private addon link for Nuvio. Our setup file then loads the same catalogs and folders we use. Takes about 10 minutes.

0 of 4 doneFree accounts only

Saved on this phone

Keys and links you enter below are kept only in this browser, never sent anywhere. Switching phones or browsers? Copy them to your notes first.

  1. Make an MDBList account

    1. Open MDBList and sign up. It's free.
    2. Go to Preferences and find API Key.
    3. Copy the key and paste it below. We'll keep it for later.
    Open MDBList ↗Preferences ↗

  2. Make a TMDB account

    1. Sign up at TMDB (free) and confirm your email.
    2. Open Settings → API and request an API key. Pick Developer, say it's for personal use.
    3. Copy the API Key (the shorter one) and paste it below.
    Sign up ↗API settings ↗

  3. Download our setup file

    It holds the catalog list only. No accounts, keys or passwords are in it.

    Download setup file

  4. Set up AIOMetadata

    1. Open AIOMetadata.
    2. Go to Import & Export → Import Configuration and choose the setup file you downloaded.
    3. Paste your TMDB API key in the TMDB section and your MDBList API key in the MDBList section. Use the buttons below.
    4. Tap Save, create a password, and you'll get Your UUID and an Install URL.
    Open AIOMetadata ↗
    Save your AIOMetadata password in your phone's password manager. It isn't stored here. You need it plus your UUID to change your setup later. Keep your Install URL private.

  5. Add it to Nuvio

    1. Tap Copy Install URL below (or Copy URL in AIOMetadata).
    2. In the Nuvio app, open Settings → Content & Discovery → Addons.
    3. Paste the link into Addon URL and tap Install.

  6. Add the homepage folders

    This replaces any collections already on the account, including Option 1.

    1. Tap Copy folders.
    2. In the Nuvio app, open Settings → Layout → Collections.
    3. Tap the clipboard icon at the top-right, paste, and tap Import.
